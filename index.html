info Cara Setup (hanya 1x)

  1. Buka Google Sheets lalu buat spreadsheet baru
  2. Klik menu Extensions → Apps Script
  3. Hapus semua kode yang ada, lalu paste isi file google-apps-script.txt
  4. Klik Deploy → New deployment → Web App
  5. Set "Execute as" = Me, "Who has access" = Anyone
  6. Klik Deploy lalu copy URL yang muncul
  7. Paste URL tersebut di kolom di bawah, klik Simpan & Sinkron
